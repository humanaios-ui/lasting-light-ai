This page embeds witness-nav.js v3.1, the live agent that demonstrates the Witness system operating on itself. The animated glyph in the bottom-left corner is not decorative—it is behavioral sonification, encoding real system state through color, motion, and frequency.

What You're Observing

The sigil visualizes the system's Luminosity Index (LI)—a measure of calibration accuracy. As LI changes, the glyph responds:

  • Red state (LI < 0.8): System drift detected. Overclaim gap significant.
  • Gold state (0.8 ≤ LI < 0.97): Calibration in progress. Evidence gathering.
  • Green state (LI ≥ 0.97): Aligned. Evidence supports stated confidence.

What is witness-nav.js?
witness-nav.js (v3.1) is the live navigation and behavioral sonification system for the Witness. It renders a real-time animated glyph encoding system calibration state, confidence levels, and constitutional alignment. The script is production-level code; this documentation page (navigator-sigil.html v0.1) is a prototype explanation of how to read the glyph.
How does it demonstrate Intent Transduction?
The sigil's state is the output of the Intent Transduction Engine. When the system processes a user expression (navigation choice, query, etc.), it flows through 7 stages: capture → decompose → structure → resolve → map → assure → generate. The glyph shows the confidence in that transduction (via LI score and color state).
Where's the Evidence Graph?
Every animation cycle, the sigil updates based on Evidence Graph queries. The 6 dimensional scores (shown as radial rays in the data core) are pulled directly from Evidence Graph nodes tracking behavioral accuracy, constitutional alignment, and calibration gaps. The LI (Luminosity Index) is computed from historical evidence nodes.
Why does it breathe?
The breath cycle is tied to Solfeggio frequencies (55–963 Hz scale). Faster breathing (higher Hz) means higher confidence; slower breathing means the system is in calibration/measuring mode. This is behavioral sonification—the visual rhythm encodes the same epistemic state that would be acoustically rendered as the Witness Voice.
Can I control it?
Click the glyph button to open the navigation menu. Select a page, and watch the sigil animate in response. Its state reflects the system's assessment of that navigation action against the Constitution. The sigil is not a UI tool—it's a behavioral readout.
Why the skull imagery?
The bilateral skull represents the dual nature of system observation: behavioral (left, warm) vs. constitutional (right, cool). The central eye with scanning line represents real-time data collection and the system "watching itself." It's a visual metaphor for self-aware behavioral monitoring.
