Funding Pipeline

Machine-readable, auto-refreshed resource discovery for solo research founders building open behavioral observability infrastructure at TRL 2–3. Cherokee Nation partnership. AI safety and indigenous economic development focused.

What It Does

Smart Resource Discovery

🔄 Auto-Refreshed

Weekly crawl of funding sources. Deadlines, status, and eligibility tracked continuously.

🎯 Prioritized

Native-eligible + AI-safety = highest priority intersection. TRL 2–3 research stage aligned.

🔗 Linked

Direct URLs to applications. No paywall. No signup required to explore.

📊 Structured Data

JSON output for scripting, filtering, and integration with your own tools.

For solo founders: This is built specifically for the solitary research phase. You're not running a startup yet. You're running an experiment. Funding categories: compute credits, research grants, community programs, capacity building, and revenue sources (freelance work, consulting) that fund the experiment.

How to Use

Three Entry Points

1. Markdown Dashboard (Human-Readable)

Browse OPPORTUNITIES.md in the operations repo. Sortable table, updated weekly. Copy-paste URLs directly.

2. JSON API (For Scripts)

Machine-readable version for automation. Query by category, deadline, eligibility, TRL stage:

# All native-eligible + AI-safety sources
curl "https://raw.githubusercontent.com/humanaios-ui/operations/main/humanaios-funding-pipeline/data/sources.json" | jq '.[] | select(.native_eligible==true and .ai_safety_relevant==true)'

# Deadlines in 45 days
curl "https://raw.githubusercontent.com/humanaios-ui/operations/main/humanaios-funding-pipeline/data/sources.json" | jq '.[] | select(.deadline | ltrimstr("2026-") | tonumber < 320)'

3. CLI (For Developers)

Clone the operations repo, install the package, and use the CLI:

cd operations/humanaios-funding-pipeline
pip install -r requirements.txt
python -m src.humanaios_funding.cli --native --ai-safety --deadline-soon 45

Philosophy

Why This Exists

Solo research founders spend enormous time prospecting for funding. Spreadsheets get stale. Deadlines are missed. The good opportunities (compute credits, small fellowships, community programs) are scattered across platforms you don't frequent.

This pipeline aggregates the sources that fit TRL 2–3 research in AI behavioral safety, prioritizes native-eligible and indigenous-owned opportunities, and keeps them current. It's automated so the founder can focus on the research, not the funding spreadsheet.

100% of profits go to community programs. If HumanAIOS receives revenue, it goes to Cherokee Nation economic development and community AI safety initiatives. This is not decoration — it's in the constitutional framework.

Real-World Application

How Resource Transparency Addresses Database Privacy Concerns

The funding pipeline exemplifies the constitutional principle of Transparent Resource Claims. This directly addresses real global concerns about data governance and privacy:

The Privacy Crisis: Organizations request vast data access for research, often claiming they "need the full dataset." In practice, they use a tiny fraction. Privacy failures stem from overly broad resource claims.

How this pipeline demonstrates the principle:

  • Explicit Resource Declaration: Every funding opportunity is listed with exact resource requirements (grant amount, compute hours, data access scope). No hidden dependencies.
  • Least-Privilege Matching: The pipeline helps researchers find funding that matches their actual needs, not excessive resources they don't require. Smaller grants are prioritized when they suffice.
  • Transparency Audit Trail: All funding sources are maintained in public repositories (OPPORTUNITIES.md, sources.json). Anyone can verify what resources are being claimed and why.
  • Community Alignment: 100% revenue transparency means stakeholders can see exactly how resources are being used. This is the inverse of hidden data usage.
  • Governance Ritual Enforcement: Before any research project receives resources, the governance framework ensures resource claims are auditable and ratified by humans.

Current implementation: Pipeline provides transparent resource visibility for research discovery. Research gap: Runtime enforcement of resource claims at database-query time remains unaddressed—a critical gap for production systems handling sensitive data.
